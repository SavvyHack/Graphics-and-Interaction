# Editor tools
Tools here can save/overwrite scenes and materials. Inspect their side effects before running. RatLevelBuilder regenerates the prototype; IntegrationSetup.Install refreshes wiring and saves; LaserPuzzleUpgrade creates a backup and modifies course layout; RatLevelSlots saves scene copies and updates build settings. None is a runtime save-game service.
Keep custom tools explicit, idempotent where practical and compatible with hand-authored levels. Respect unsaved scenes; use Undo/dirty marking where appropriate. Do not auto-generate geometry from startup hooks. Preserve coursework workflow files. Update path/build-entry assumptions in PrototypePlayMode and validators when introducing Home; do not run destructive generation merely to satisfy an outdated check.
