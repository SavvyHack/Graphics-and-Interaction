# Game Design Document (GDD)

Similar to Project 1, this file should contain the Game Design Document (GDD) for your game. You are welcome to copy your GDD from Project 1 into this file. Read the [Project 1 specification](https://github.com/feit-comp30019/project-1-specification) again for details on what _actually_ needs to be covered in the GDD. If changes to the game design are made during the further development of the game for Project 2, you are **responsible** for keeping this section updated with your latest design.

From this point onward, you no longer need to update the GDD in your Project 1 repository.
