## Gameplay and persistence
One GameManager, RatLifeManager and PlayerRatController per level. Three rats on New Game; survivors carry into the next level and retry restores the level-entry count. Checkpoint respawn, input-safe pause and puzzle reset. Stages 3-7 are five-floor enclosures generated by `EnclosureLevelBuilder` from Augmentation Lab. They introduce dash, wall jump, glide/updrafts, phase and ground pound; see [levels 3-7](levels/enclosure-levels-3-7.md). Source stages have the required jetpack, double jump, shield, speed, gravity pulse and Slow Time augments. Shields do not protect against falls/deep coolant. Cyan stations recharge; gold tokens respawn each attempt and add to the saved wallet. Magnetic gates stay open during the attempt; reset clears temporary powers and replenishes stations.

`CampaignProfile` is the sole PlayerPrefs JSON writer for unlocks, stable coin IDs, purchases, equipped outfit, settings and statistics. `CampaignSession` journals attempts and active time. All 140 coins are unique. New Game retains tokens, outfits, settings and lifetime records. Continue restarts a level. Isolated validators use temporary keys and remove them afterward. Stages 1-2 retain `enclosure`/`transfer` IDs, so old token progress and purchases survive layout replacement.

`FixedCameraFollow` shares snap/follow bounds, fixes depth/rotation, avoids zero-delta smoothing, clears shader targets on disable and expands the view in narrow windows. Source stages use this owner rather than the source camera component. Active-glass shader target publication is retained.
